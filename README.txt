Vai-Bon Store (ভাই-বোন রেশন এন্ড ভ্যারাইটিজ স্টোর)

Open index.html in a browser (or Visual Studio / Live Server).

index.html      - page content (text, product names, prices, contact)
css/style.css   - colors, layout, design
images/         - all photos (replace a file with the same name to change a picture)
